## 安装前必读

- 从 v0.0.20 / v0.0.21 升级：直接覆盖安装（同一把签名密钥，数据保留）。

## 新增

- **书源：露露书**（www.lulushu55.com）。可搜索、按书名打开、粘贴书页/章节网址打开、在线阅读。正文由网页里给出的校验码再请求一次取得（浏览器打开网页时也是这样取的），不涉及登录或人机验证。
- **占位章换源多一个来源**：顺序为本机同名书 → 飘天文学 → 露露书 → 万书阁 → 69书吧。飘天文学请求过快会返回 429，此时由露露书补上；实测在飘天文学不可用时，《万古神帝》第 3579、3595 章约 5 秒内从露露书自动补全。露露书的章节号又是另一套（“第三千五百五十八章 回城”），照样按章名匹配。
