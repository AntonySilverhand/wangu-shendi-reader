# v0.0.20：占位章自动换源

## 安装前必读

- 从正式发布的版本升级：可以直接覆盖安装（发布密钥固定不变）。
- v0.0.17–v0.0.19 没有在 GitHub 上发布过；本版同时包含 [v0.0.19](v0.0.19.md) 的全部改动（69书吧、爱下电子书、导入/导出/返回键修复、清理站点广告等），升级前请先看那份说明里的“安装前必读”。

## 新增

- **占位章自动换源**：源站把“本章节内容正在手打中，请稍后刷新…”之类的占位文字当正文时，阅读器会在后台自动用书名到其他在线书源搜索同一本书、按章节标题找到这一章并显示正文，不需要任何操作。顶部只留一行小字“内容来自××（不影响原书数据）”。
  - 换来的内容只用于本次显示，不写入缓存，原书的目录、进度、书签都不变；源站以后补上正文时照常显示原书源内容。
  - 其他书源也没有这一章时，提示“当前书源暂无本章内容，其他书源也未找到”。
  - 关掉“清理站点广告”也能识别占位章。
  - 目前能逐章在线获取的只有万书阁与 69书吧，两者互为备选；爱下电子书是整本下载型，不参与换源。

## 修复

- 章首提示框隐藏时仍占一块空白（`hidden` 被 `display: flex` 覆盖）。

## 已知情况

- 69书吧整站有 Cloudflare 人机验证。网络环境拿到验证页时换源会失败，回退为“其他书源也未找到”的提示；阅读器不会尝试绕过验证。
