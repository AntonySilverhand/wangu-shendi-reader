# v0.0.21：新书源飘天文学；占位章自动换源更准、翻页不闪

## 安装前必读

- 从 **v0.0.20** 升级：直接覆盖安装（同一把签名密钥，数据保留）。
- 更早的版本（v0.0.19 及以前）与 v0.0.20 起的签名密钥不同，需要先在旧版 **设置 → 导出书签与进度**，卸载后安装，再导入。

## 新增

- **书源：飘天文学**（www.piaotia.com）。可搜索、按书名打开、粘贴书页/章节网址打开、在线阅读；正文是纯 HTML，开发环境实测可直接访问。《万古神帝》在万书阁和爱下电子书里是占位文字的第 3578、3579、3582、3583、3595、3602 章，这里都有完整正文。

## 改进

- **占位章自动换源**（“本章节内容正在手打中…”这类）：
  - 来源顺序：本机已下载/导入的同名书 → 飘天文学 → 万书阁 → 69书吧，不需要任何操作；章首一行说明正文来自哪里。
  - 各站章节号常常对不上（同一章“第3579章 回城”在别站是“第三千五百五十八章 回城”，“第3595章 谋未来”在飘天文学是第 3664 章），现在按**章名**匹配，同名章节按在全书中的位置取最近的一章；书名和作者必须一致，不再用搜索结果的第一本。
  - 读到前一章时，如果下一章是占位章，会提前在后台换源，翻页直接显示正文，不再先闪一下占位文字；同一次阅读里回到这一章也直接显示。
  - 整本下载的书（如爱下电子书版《万古神帝》）里的占位章同样会自动补全。
  - 换来的正文只用于显示，不覆盖原书缓存、目录、进度和书签；“清理站点广告”设置同样适用。
- 书架上非默认书源的书都标注书源名（之前只有 69书吧）。

## 已知情况

- 繁体书名（如导入的“萬古神帝”）在简体书源里搜不到，这类书的占位章暂时无法自动换源。
- 69书吧整站有 Cloudflare 人机验证，被拦截时自动跳过、试下一个来源。
- 飘天文学连续请求过快会返回 429；正常阅读（一章一章看）不受影响。
- 搜索书源页面在 320px 宽的屏幕上会横向多出 16px（之前就有）。
