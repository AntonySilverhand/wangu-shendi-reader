# v0.0.18：修复第三千四百零二章之后跳章
## ⚠️ 安装前必读：需要先卸载旧版

v0.0.16 的签名密钥没有保留下来，本版换成了一把**今后固定使用**的发布密钥，所以这次**不能覆盖安装**，必须先卸载旧版。卸载会清空 App 内的数据，请按顺序操作：

1. 在旧版里打开 **设置 → 导出书签与进度**，把 JSON 文件存到手机里。
2. 卸载旧版，安装本 APK。
3. 打开 **设置 → 导入书签与进度**，选择刚才的文件。

已缓存的正文会在阅读时重新下载；导入过的本地 TXT 需要重新导入。从本版起固定使用这把密钥，之后的版本可以直接覆盖升级。

## 修复

- **跳章**：源站在第3409章之后从“第三千三百八十九章”重新编号，第二段与第一段章号重复。旧的目录合并规则把同号的占位标题（“分节阅读第N节”）当作重复上传丢弃，还会让有标题的条目顶替同号占位，于是读完“第三千四百零二章 进始祖界修为大进”后直接跳到“第三千四百零四章 时间缓流区”。现在只有章节 id 相差很大的结尾整批重传才算重复，同批次内的同号章节全部保留（宁多勿少）。目录会从已缓存的分页重新合并，阅读进度不受影响。
- 同样的修复也同步到了开发中的原生 App（`android-native`）。
