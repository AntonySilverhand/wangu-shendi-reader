# v0.0.13 修复与验证

## 修复

- 目录 freeze 根因：`renderSearch → loadAllForSearch → loadAll` 在目录含失败页、`isComplete=false`、没有可加载页时形成无网络等待的微任务闭环。渲染现在不启动任务；搜索有 debounce、generation、AbortController 和明确的穷尽状态。失败页只由用户重试，数字查询先定位单页，文本查询渐进扫描。
- Android origin 固定为 `https://reader.local/`，由 WebViewClient 从 APK assets 提供资源，不再启用随机端口本地服务器。原生书源传输逐跳验证域名/协议/端口/书籍路径；保留 404 分页探针语义；首页使用 HTML MIME。
- 进度、书签、历史同步写 localStorage。切章先保存旧章位置，新章渲染后立即记录恢复锚点或起点；同章书签跳转不再被去重逻辑忽略；保存失败有日志和数据面板诊断。
- 章节打开有 generation 与取消，返回首页/切书取消加载；原生 fetch 传递 signal。后台补全和手动重载均不以更短正文覆盖旧正文。
- 布局统一使用 compact (<840)、medium (840–1599)、wide (≥1600)；wide 为三栏 Grid。resize 保留同一 Reader/目录实例，无持续轮询。
- 旧 WebView 搜索只标记当前命中，保留全部匹配导航；现代浏览器最多绘制500个普通高亮与当前命中。

```bash
npm run typecheck
npm test
bash tools/verify.sh
bash tools/reader-server.sh start 8787
node test/e2e.mjs http://localhost:8787 1
node test/e2e.mjs http://localhost:8787 2
node test/verify-delivery.mjs
node test/check-layout.mjs
node test/search-regression.mjs
node test/lifecycle-regression.mjs
bash android/build.sh 0.0.13
node tools/android-persistence.mjs
DEBUG=1 bash android/build.sh 0.0.13
```

已执行：58个单测、两段 E2E 各29项、交付验证、动态布局、搜索60秒浸泡、生命周期回归及 Chromium 同磁盘 profile 持久化验证均通过。目录无结果穷尽后的60秒内新增目录请求0，render计数26→26；快速输入只启动1个任务、加载5页而非全44页。

最终复跑备注：一次 `verify.sh` 遇到8787端口占用并误连旧预览服务，停止旧服务后重新验证通过。搜索浸泡此前完整通过；最近一次复跑在25秒时被会话中断，当时 render=26、新请求0、输入可编辑，不能把该次中断运行计为60秒通过。

`tools/android-persistence.mjs` 是桌面 Chromium **正常关闭/重新打开**测试，不是 WebView 或 force-stop。不同端口负对照使用**同一 profile**，仅改变 origin。它不能验证 Java 拦截器、Android 生命周期或设备落盘时序。

## Android 真机验收（本环境未执行）

本环境没有 adb/emulator/连接设备。release/debug APK 构建及 aapt versionCode=13 / versionName=0.0.13 检查通过，不代表真机运行通过。

在已授权的专用测试设备上运行（不会清数据，会添加一份测试TXT）：

```bash
# 需要 Android SDK 构建工具、adb、Node、npm install、已连接设备
bash tools/android-persistence-adb.sh 0.0.13
```

脚本安装同签名 debug APK，通过 adb 转发 WebView DevTools/CDP：真实导入TXT、滚动、添加书签和设置；保存 LS/IDB 快照；`am force-stop` 后重启；比对全部记录并打开本地书检查非章首恢复。成功后生成 `artifacts/android-device-persistence.json`。脚本尚未在设备上验证；若设备不开放 `/proc/net/unix`，需要手动使用 Chrome inspect 找到 DevTools socket。release APK 不开放 WebView 调试，无 intent JS/Toast 调试桥。

还应手工验证：章节/多个书签跳转后立即 force-stop、清正文缓存不清个人数据、旋转/折叠/分屏时搜索焦点与阅读锚点、断网启动TXT、慢源重试、至少60秒无结果搜索操作。桌面 resize 不能代替折叠屏实机测试。

## 升级注意

旧版随机端口 origin 下的数据不能由新 origin 自动读取。升级前若旧版仍可访问，请先从数据面板导出个人数据，再在新版导入；本地 TXT 请保留原文件后重新导入。**不要为排障卸载应用或清除应用数据。** APK 覆盖安装与未来稳定 origin 可避免再次因端口变化隔离数据，但不能承诺自动找回此前已经不可访问的旧 origin 数据。

本版本作为预发布提供，待 Android 实机验收后再标记稳定版。
